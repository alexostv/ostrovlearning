# Сайт-курс испанского языка

Это статический сайт, который можно открыть локально в браузере или разместить на бесплатном хостинге.

## Быстрый старт (для просмотра локально)

Чтобы сайт работал, его нужно открывать через локальный веб-сервер, а не двойным кликом по `index.html`. Это связано с тем, как браузеры загружают JSON-файлы.

### На Windows

Дважды кликни по файлу `start-server.bat`. Откроется чёрное окно с командой и сообщением "Serving HTTP on...".

Затем открой в браузере: http://localhost:8000

Чтобы остановить сервер - закрой окно или нажми `Ctrl+C`.

### На Mac / Linux

Открой терминал в этой папке и выполни:

```bash
bash start-server.sh
```

Затем открой http://localhost:8000

### Что нужно установить

На Windows и Mac обычно уже установлен Python. Проверить можно командой `python --version` или `python3 --version` в терминале. Если Python не установлен, скачай с python.org (бери последнюю версию 3.x).

## Структура папок

```
site/
├── index.html              Главная страница (список модулей)
├── module.html             Страница модуля (теория + упражнения)
├── about.html              О курсе
├── assets/
│   ├── styles.css          Дополнительные стили
│   ├── app.js              Главная логика (загрузка модулей, прогресс)
│   └── exercises.js        Логика упражнений
├── content/
│   ├── courses.json        Список всех модулей курса
│   └── modules/            Папка с файлами модулей
│       ├── A0-01-saludos.json
│       └── A0-02-alfabeto.json
└── templates/
    └── module-template.json   Шаблон для нового модуля
```

## Как добавить новый модуль

1. Скопируй файл `templates/module-template.json` в папку `content/modules/`
2. Переименуй его, например в `A0-03-numeros.json`
3. Открой в любом редакторе (рекомендую **VS Code**, бесплатный) и заполни поля
4. Открой `content/courses.json` и добавь идентификатор модуля в список `modules`
5. Сохрани файлы и обнови страницу в браузере (F5)

Подробное руководство со всеми типами теории и упражнений: смотри файл `Руководство_преподавателя.md` в корневой папке проекта.

## Как разместить сайт в интернете

Когда готов поделиться с учениками, есть несколько бесплатных вариантов. Самый простой - **Netlify Drop**:

1. Зайди на https://app.netlify.com/drop
2. Перетащи всю папку `site` в окно
3. Получишь ссылку вида `https://random-name-12345.netlify.app`
4. Можно подключить свой домен (платно, около 1000-1500 руб/год)

Альтернативы: GitHub Pages, Cloudflare Pages, Vercel. Все бесплатные для таких сайтов.

## Где сохраняется прогресс учеников

Прогресс хранится в браузере ученика (localStorage). Это значит:

- Прогресс сохраняется между визитами на одном устройстве
- Прогресс **теряется** при очистке кеша или смене устройства
- Преподаватель не видит прогресс учеников

Если позже захочешь сохранение прогресса с аккаунтами - это отдельный этап (см. план архитектуры).
